# 01 - Thesis Scope and Research Questions

## Scope freeze (single sentence)
Evaluate whether HITL checkpoints in a financial-risk chat workflow improve output quality and user trust versus baseline automation, with acceptable time cost.

## In-scope
- Controlled within-subjects protocol using assigned mode order.
- Primary task runs with fixed ticker and fixed query per phase.
- Four modes as currently modeled: `baseline`, `hitl_r`, `hitl_g`, `hitl_full`.
- Post-task questionnaire per phase.
- Audit and timing capture for core study actions.

## Out-of-scope
- New enterprise product features beyond study needs.
- Open-ended conversational exploration as part of primary outcomes.
- Full production hardening (auth, RBAC, infra SLAs).

## Primary research questions (RQ)
1. RQ1 (Quality): Does HITL intervention improve factual quality/relevance vs baseline?
2. RQ2 (Trust): Do HITL modes improve user confidence/trust vs baseline?
3. RQ3 (Effort): What time/effort increase accompanies quality/trust gains?
4. RQ4 (Mode effects): How do retrieval-first vs generation-first intervention paths differ?

## Secondary questions (exploratory)
- Which intervention point catches more unsupported claims?
- Does explicit chunk curation change perceived citation usefulness?
- Do users prefer one intervention pattern over another?

## Anchoring values to preserve
- Trust
- Human accountability
- Auditability
- Governance fit
- Quality control
- Measured impact
