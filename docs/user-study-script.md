# User Study Script (Researcher Guide)

**Version:** 1.0 | **Date:** 5 April 2026
**Session duration:** 30-40 minutes
**Platform:** Microsoft Teams (screen share + audio recording)

---

## Pre-Session Checklist (before participant joins)

- [ ] FinRisk backend running, DB seeded with assignments
- [ ] Confirm participant ID and assignment (check condition order)
- [ ] Have ready: Consent Form, Demographics Form, Participant Information Sheet
- [ ] Teams meeting link sent to participant
- [ ] Screen recording software ready
- [ ] Note participant's condition order: Baseline first or HITL-Full first

---

## 1. Welcome & Consent (~3 min)

**Say:**
> "Hi [name], thanks for joining. This session will take about 30 to 40 minutes. You'll be using a system called FinRisk that generates financial risk summaries from real SEC 10-K filings. You'll complete two tasks using different modes of the system, and I'll ask you some questions at the end. There are no right or wrong answers -- I'm interested in your honest experience."

**Do:**
- Share Participant Information Sheet (v5) -- give them a moment to read
- Share Consent Form (v5) -- participant signs digitally
- Share Demographics Form -- participant fills in (takes ~2 min)

**Say:**
> "I'll start recording now. Feel free to think aloud as you go -- any reactions, confusion, or thoughts are really useful for the research."

- [ ] Start screen + audio recording

---

## 2. Tutorial with P00 / WMT (~5 min)

**Say:**
> "Before we start the real tasks, let's do a quick walkthrough so you're comfortable with the interface."

**Do:**
- Open FinRisk, enter participant ID (use P00 for tutorial)
- System loads WMT in HITL-Full mode

**Walk through:**

1. **Query submission** -- "This is the query the system will answer. Click to submit."
2. **Retrieved chunks** -- "These are sections the system pulled from Walmart's annual filing. You can expand each one to read it."
3. **Chunk selector** -- "In some modes you can choose which sections to keep. Try unchecking one that seems less relevant."
4. **Summary generation** -- "Click continue to generate the summary from your selected chunks."
5. **Summary editor** -- "Here you can edit the text, fix wording, or remove anything you think is wrong. Try making a small change."
6. **Questionnaire** -- "After each task you'll answer a few quick questions about the output."

**Say:**
> "In the first/second task you'll have these controls. In the other task the system handles everything automatically and you just review the output. Ready to start?"

---

## 3. Task 1: Condition A (~10 min)

**Do:**
- Start session with actual participant ID (e.g., P01)
- System loads Phase 1 with assigned mode and ticker

**If Baseline, say:**
> "In this mode, the system retrieves and generates automatically. You'll review the output but can't change it. Take your time reading through."

**If HITL-Full, say:**
> "In this mode, you can select which retrieved sections to include and edit the generated summary. Do whatever feels natural -- there's no pressure to change things if you think they're fine."

**During task:**
- Stay quiet, let participant think aloud naturally
- Note any verbal reactions or hesitations
- Don't guide or hint at answers

**After questionnaire appears:**
> "Take a moment to fill this in. Just your honest impression."

- [ ] Participant completes post-task questionnaire

---

## 4. Task 2: Condition B (~10 min)

**Say:**
> "Now we'll move to the second task. This one uses a different mode."

**Do:**
- Click advance to next phase
- System loads Phase 2 with the other mode and ticker

**Brief the mode (same as above, whichever wasn't used in Task 1)**

**During task:**
- Same approach -- stay quiet, note observations

- [ ] Participant completes post-task questionnaire

---

## 5. Post-Study Reflection (~5 min)

**Ask verbally, note responses:**

> "You just used two different modes. Which did you prefer and why?"

> "Which summary did you trust more?"

> "Was there anything frustrating or confusing about either mode?"

---

## 6. Closing Interview (~5-10 min)

**Say:**
> "I'd like to ask a few more questions. There are no right answers, just want your perspective."

**Questions:**

1. "How did your trust in the system's output differ between the two modes?"
2. "How useful was being able to select which sections to include?" *(HITL-Full)*
3. "How useful was being able to edit the summary?" *(HITL-Full)*
4. "Did having control change how you judged the final output?"
5. "Would you use a system like this in a real work context? Under what conditions?"
6. "What would you change or improve?"

**Probe as needed** -- follow up on interesting answers, don't rush.

---

## 7. Debrief & Close (~2 min)

**Say:**
> "That's everything. Thanks so much for your time. Your feedback is really valuable for this research. I'll process the compensation within the next few days. If you have any questions later, feel free to email me at bm24aaq@herts.ac.uk."

**Do:**
- [ ] Stop recording
- [ ] Thank participant, let them leave the call
- [ ] Save recording files with participant ID (e.g., P01_recording)
- [ ] Note any post-session observations while fresh
