# 06 - Pilot Runbook (2-3 Participants)

## Pilot purpose
Validate protocol clarity, system stability, and data completeness before full study collection.

## Pre-pilot prep
1. Confirm locked protocol config is active.
2. Verify required checkpoints/instruments are enabled.
3. Run one internal dry run per mode.
4. Prepare facilitator script and incident sheet.

## Facilitator script (compact)
1. Explain task goal and interaction constraints.
2. Emphasize that evidence-based review is required.
3. Start session and observe silently unless blocked.
4. Record confusion points and technical issues.
5. Capture participant feedback after each phase.

## Pilot acceptance criteria
1. Participants complete all phases without protocol ambiguity.
2. No missing mandatory fields in phase records.
3. Timing and checkpoint events are complete and consistent.
4. At least one full session completes without manual DB correction.

## Pilot output artifact
After pilot, produce a short memo with:
- observed friction points
- protocol changes needed
- blocking bugs
- go/no-go for full study
