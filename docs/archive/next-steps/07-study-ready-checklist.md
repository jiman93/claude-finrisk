# 07 - Study-Ready Checklist

Use this checklist before recruiting full participants.

## Protocol
- [ ] Scope and RQs frozen.
- [ ] Inclusion/exclusion rules documented.
- [ ] Deviations policy documented.

## System behavior
- [ ] Required checkpoints enforce progression.
- [ ] Post-task questionnaire is mandatory.
- [ ] Task/session completion is backend-marked.
- [ ] Mode order and phase assignments verified.

## Data integrity
- [ ] All required fields persist in backend.
- [ ] Checkpoint events use stable instance IDs.
- [ ] No critical data exists only in frontend state.
- [ ] Data export is analyzable without manual patching.

## Reliability
- [ ] Fallback behavior tested and logged.
- [ ] Failure handling tested (timeout, API error).
- [ ] Recovery path documented.

## Pilot readiness
- [ ] 2-3 participant pilot completed.
- [ ] Pilot findings resolved or accepted with rationale.
- [ ] Go decision signed off.
